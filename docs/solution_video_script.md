## Production Tips for Recording
1. **Resolution:** 1920x1080 (1080p).
2. **Terminal:** Run `python -m ui.server 8080` and show the clean web UI at `http://127.0.0.1:8080`.
3. **Tabs to Demonstrate:**
   - Tab 1: **Candidate Assessment** (Scatter quadrant canvas with crosshairs and hover tooltip, Alexander Sterling centerpiece, Priority Questions + Copy button).
   - Tab 2: **Discrepancy Diffs** (Side-by-side quote highlight and 'View in Dossier' button).
   - Tab 3: **Dossier Viewer** (Multi-doc tabs).
   - Tab 4: **Benchmark Matrix** (Spearman rho, Brier score, ECE).
   - Tab 5: **Audit & Governance** (EEOC fairness, grounding fidelity, adversarial defense).
4. **Ollama:** Confirm Ollama daemon is running with `qwen2.5:3b` or running in offline mock mode ($0.00 cost).
